# Static IP Products

## Overview

Static IP Products are the service offerings provided by Ziply to customers requiring fixed IP address allocation. The two primary products—BFI (Business Fiber Internet) and BF Pro (Business Fiber Pro)—support static IP allocation in two standardized CIDR block sizes.

## Key Facts

- **BFI (Business Fiber Internet)**: Enterprise-grade connectivity with static IP support (Source: [static-ip-global-change-orders](wiki/sources/static-ip-global-change-orders.md), 2026-10-21)
- **BF Pro (Business Fiber Pro)**: Premium Business Fiber option with static IP support (Source: [static-ip-global-change-orders](wiki/sources/static-ip-global-change-orders.md), 2026-10-21)
- **Static IP Options**: Two sizes available (Source: [static-ip-global-change-orders](wiki/sources/static-ip-global-change-orders.md), 2026-10-21)
  - Static IP 1 (/30): 1 usable IP (Source: [static-ip-global-change-orders](wiki/sources/static-ip-global-change-orders.md), 2026-10-21)
  - Static IP 5 (/29): 5 usable IPs (Source: [static-ip-global-change-orders](wiki/sources/static-ip-global-change-orders.md), 2026-10-21)
- **Use Cases**: (Source: [static-ip-global-change-orders](wiki/sources/static-ip-global-change-orders.md), 2026-10-21)
  - Hosting public services (Source: [static-ip-global-change-orders](wiki/sources/static-ip-global-change-orders.md), 2026-10-21)
  - Firewall configuration (Source: [static-ip-global-change-orders](wiki/sources/static-ip-global-change-orders.md), 2026-10-21)
  - VPN access (Source: [static-ip-global-change-orders](wiki/sources/static-ip-global-change-orders.md), 2026-10-21)
  - Remote connectivity (Source: [static-ip-global-change-orders](wiki/sources/static-ip-global-change-orders.md), 2026-10-21)
  - Application hosting (Source: [static-ip-global-change-orders](wiki/sources/static-ip-global-change-orders.md), 2026-10-21)
  - DNS configuration (Source: [static-ip-global-change-orders](wiki/sources/static-ip-global-change-orders.md), 2026-10-21)
  - Hosting servers (Source: [static-ip-global-change-orders](wiki/sources/static-ip-global-change-orders.md), 2026-10-21)
  - Remote access systems (Source: [static-ip-global-change-orders](wiki/sources/static-ip-global-change-orders.md), 2026-10-21)

## Static IP Allocation Options

### Static IP 1 (/30)
- **Total IPs**: 4
- **Usable IPs**: 1
- **Use Cases**: Single server hosting, VPN endpoint, DNS hosting

### Static IP 5 (/29)
- **Total IPs**: 8
- **Usable IPs**: 5
- **Use Cases**: Multiple servers, load-balanced endpoints, redundant services
