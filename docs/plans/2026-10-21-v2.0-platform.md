# Milestone v2.0 Platform Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Implement Milestone v2.0 Platform (LLM-First Knowledge Engine) delivering deterministic knowledge graph manifests, dense semantic indexing for sub-cent LLM retrieval, multi-LLM instruction synchronization, and pluggable source format adapters.

**Architecture:** A zero-external-dependency, stdlib-first architecture organized into 3 sequential stacked PRs:
1. `feature/issue-20-23-graph-and-semantic-index`: Compiles `wiki/graph.json` (nodes and typed directed edges) and `wiki/semantic-index.json` (dense keyword maps and summaries) with lint integration.
2. `feature/issue-22-multi-llm-adapters`: Delivers dedicated agent instructions (`CLAUDE.md`, `.gemini/GEMINI.md`, `.cursorrules`) with a deterministic synchronization engine (`scripts/sync-adapters.py`).
3. `feature/issue-19-pluggable-source-adapters`: Implements a modular adapter framework in `adapters/` (URL, PDF, CSV, GitHub issues) converting heterogeneous inputs into clean markdown in `raw/`.

**Tech Stack:** Python 3.10+ (standard library only for core operations: `json`, `re`, `argparse`, `pathlib`, `unittest`, `urllib`), Shell (`.sh`), PowerShell (`.ps1`).
